# Créditos dos assets
- **Catacombs tileset / tochas**: Szadi art — domínio público, uso livre (crédito opcional, mas apreciado). Não revender o pacote.
- **Scary Mobs** (lobisomens e homens-tubarão): pacote de monstros em pixel art. O pacote recebido não informa autor, página original ou licença; esses dados devem ser adicionados quando confirmados.

- **Osso do jogador**: asset do pacote de integração nomeado originalmente `Skull&Bones - FrodoUndead (1).png`; exibido em 16×8.
- **Projétil inimigo**: criado para o projeto.
